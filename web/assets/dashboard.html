🚀 Visión General y Arquitectura

PBX AI es una plataforma de telefonía y mensajería impulsada por Inteligencia Artificial que conecta centrales telefónicas Asterisk (mediante FastAGI), interfaces de chat web, WhatsApp y Telegram con modelos de lenguaje de última generación y motores de síntesis de voz (TTS) y reconocimiento de voz (ASR).

FastAGI Telefonía Asterisk

Escucha en el puerto TCP 4573. Contesta llamadas, reproduce audio en tiempo real y transcribe la voz del interlocutor para interactuar con el LLM.

SSE & REST Web Chat & Streaming

Disponible en /chat con respuestas fluidas transmitidas token por token mediante Server-Sent Events (SSE) y soporte de audio VAD en el navegador.

Multi-LLM Conectores de IA

Compatible con cualquier API estándar OpenAI (OpenAI GPT-4o, Anthropic Claude vía proxy, Ollama en local, Groq de ultra baja latencia, DeepSeek).

Multi-TTS Síntesis de Voz

Soporte nativo para Google Translate TTS, ElevenLabs (voces hiperrealistas) y OpenAI TTS con almacenamiento en caché inteligente.

📞 Conexión con Asterisk (FastAGI)

PBX AI se comunica con Asterisk a través de FastAGI en el puerto TCP 4573. Asterisk delega el control de la llamada a PBX AI, quien transcribe el audio del llamante con ASR, consulta al modelo LLM y sintetiza la respuesta con TTS directamente hacia el canal de voz.

📄 Ejemplo 1: Dialplan Directo (extensions.conf)

Agrega esta extensión a tu archivo /etc/asterisk/extensions.conf para que cualquier llamada a la extensión 900 sea atendida por el bot de IA:

/etc/asterisk/extensions.conf 
[from-internal]
; Extensión 900: Asistente Telefónico PBX AI
exten => 900,1,NoOp(--- Llamada entrante a PBX AI Assistant ---)
 same => n,Answer()
 same => n,Wait(1)
 same => n,AGI(agi://127.0.0.1:4573)
 same => n,Hangup()

📄 Ejemplo 2: Menú IVR con Opción DTMF (*)

Permite a los usuarios marcar * en cualquier momento para hablar con el agente de IA:

IVR con DTMF 
[main-menu]
exten => s,1,Answer()
 same => n,Background(custom/welcome-menu)
 same => n,WaitExten(5)

; Si presiona * o dice 'agente', transferir a PBX AI
exten => *,1,NoOp(--- Transferencia a PBX AI ---)
 same => n,AGI(agi://127.0.0.1:4573)
 same => n,Hangup()

⚙️ Requisitos de Conversión de Audio

Asterisk requiere audio a 8000 Hz, mono, PCM de 16 bits (.wav / .sln). PBX AI utiliza ffmpeg y sox en el servidor para realizar las conversiones automáticamente en milisegundos.

⚙️ Referencia de Flags de Línea de Comandos

Puedes arrancar PBX AI con las siguientes opciones en terminal o configurarlas en pbx.json:

Flag Tipo Defecto Descripción
--start bool false Inicia el servidor web, el servicio AGI y los listeners de webhooks.
--db-setup bool false Inicializa las tablas y datos por defecto en SQLite o MySQL.
--wizard bool false Asistente interactivo por consola para configurar pbx.json.
--chat bool false Habilita la interfaz web de chat en /chat y el dashboard en /dashboard.
--web-port int 35248 Puerto HTTP para el Dashboard, Chat, Métricas Prometheus y APIs.
--asterisk bool false Activa el servidor FastAGI para atender llamadas de Asterisk.
--asterisk-agi string 127.0.0.1:4573 Dirección y puerto TCP donde escuchará el servidor FastAGI.
--ai-token string "" API Key del proveedor LLM (OpenAI, Groq, OpenRouter).
--llm-url string "" URL base del endpoint OpenAI-compatible (ej. http://localhost:11434/v1).

💾 Parámetros en Base de Datos (Tabla aiSettings)

Puedes modificar estos valores en vivo sin reiniciar el servidor desde el Menú de Administración (/):

  • llm_url: Endpoint de chat completions compatible con OpenAI.
  • ai_token: Clave de acceso a la API del modelo de IA.
  • model: Nombre del modelo (ej. gpt-4o-mini, llama-3.3-70b-versatile).
  • asr: Proveedor de reconocimiento de voz (google, openai).
  • tts: Proveedor de voz sintetizada (google, openai, elevenlabs).
  • timezone: Zona horaria local para marcas de tiempo (ej. America/Mexico_City).

📝 Prompts por Canal (Tabla aiPrompts)

PBX AI permite definir instrucciones personalizadas según el medio de contacto:

  • Canal `asterisk`: Instruye al LLM para que responda con frases breves, directas, sin caracteres especiales ni emojis, ideal para ser leído por teléfono.
  • Canal `chat`: Permite respuestas más detalladas, listas con viñetas, enlaces y formato Markdown.
  • Canal `all`: Prompt base del sistema compartido por todos los canales.

🛠️ Preguntas Frecuentes & Resolución de Problemas

❓ Asterisk reporta "AGI Connection Refused" en el puerto 4573

Causa: PBX AI no arrancó con el servicio Asterisk habilitado.
Solución: Asegúrate de incluir la flag --asterisk al iniciar el comando:
./build/pbx --start --asterisk --asterisk-agi 127.0.0.1:4573

❓ Recibo error "HTTP 429 Too Many Requests"

Causa: El limitador de tasa de seguridad de PBX AI restringe peticiones a 60 req/min por dirección IP para prevenir ataques de denegación de servicio y saturación de API.
Solución: Espera 60 segundos o revisa si algún script automatizado está enviando peticiones en bucle.

❓ Error: "no such table: aiLogs" o faltan datos

Causa: La base de datos SQLite o MySQL no ha sido inicializada.
Solución: Ejecuta el inicializador de base de datos una sola vez:
./build/pbx --db-setup --db-name pbx.db

❓ El audio de la llamada no se reproduce o se escucha en blanco

Causa: Falta la utilidad ffmpeg o sox en el sistema operativo del servidor para convertir archivos de audio temporal.
Solución: Instálalo mediante el gestor de paquetes de tu sistema:
En Debian/Ubuntu: sudo apt update && sudo apt install -y ffmpeg sox libsox-fmt-all
En macOS: brew install ffmpeg sox
