Centro de Ayuda y Guía Completa PBX AI

Documentación técnica, integración Asterisk FastAGI, configuración de LLMs y resolución de dudas.

🚀 Visión General y Arquitectura

PBX AI es una plataforma de telefonía y mensajería impulsada por Inteligencia Artificial que conecta centrales telefónicas Asterisk (mediante FastAGI), interfaces de chat web, WhatsApp y Telegram con modelos de lenguaje de última generación y motores de síntesis de voz (TTS) y reconocimiento de voz (ASR).

FastAGI Telefonía Asterisk

Escucha en el puerto TCP 4573. Contesta llamadas, reproduce audio en tiempo real y transcribe la voz del interlocutor para interactuar con el LLM.

SSE & REST Web Chat & Streaming

Disponible en /chat con respuestas fluidas transmitidas token por token mediante Server-Sent Events (SSE) y soporte de audio VAD en el navegador.

Multi-LLM Conectores de IA

Compatible con cualquier API estándar OpenAI (OpenAI GPT-4o, Anthropic Claude vía proxy, Ollama en local, Groq de ultra baja latencia, DeepSeek).

Multi-TTS Síntesis de Voz

Soporte nativo para Google Translate TTS, ElevenLabs (voces hiperrealistas) y OpenAI TTS con almacenamiento en caché inteligente.

📞 Conexión con Asterisk (FastAGI)

PBX AI se comunica con Asterisk a través de FastAGI en el puerto TCP 4573. Asterisk delega el control de la llamada a PBX AI, quien transcribe el audio del llamante con ASR, consulta al modelo LLM y sintetiza la respuesta con TTS directamente hacia el canal de voz.

📄 Ejemplo 1: Dialplan Directo (extensions.conf)

Agrega esta extensión a tu archivo /etc/asterisk/extensions.conf para que cualquier llamada a la extensión 900 sea atendida por el bot de IA:

/etc/asterisk/extensions.conf 
[from-internal]
; Extensión 900: Asistente Telefónico PBX AI
exten => 900,1,NoOp(--- Llamada entrante a PBX AI Assistant ---)
 same => n,Answer()
 same => n,Wait(1)
 same => n,AGI(agi://127.0.0.1:4573)
 same => n,Hangup()

📄 Ejemplo 2: Menú IVR con Opción DTMF (*)

Permite a los usuarios marcar * en cualquier momento para hablar con el agente de IA:

IVR con DTMF 
[main-menu]
exten => s,1,Answer()
 same => n,Background(custom/welcome-menu)
 same => n,WaitExten(5)

; Si presiona * o dice 'agente', transferir a PBX AI
exten => *,1,NoOp(--- Transferencia a PBX AI ---)
 same => n,AGI(agi://127.0.0.1:4573)
 same => n,Hangup()

⚙️ Requisitos de Conversión de Audio

Asterisk requiere audio a 8000 Hz, mono, PCM de 16 bits (.wav / .sln). PBX AI utiliza ffmpeg y sox en el servidor para realizar las conversiones automáticamente en milisegundos.

⚙️ Referencia de Flags de Línea de Comandos

Puedes arrancar PBX AI con las siguientes opciones en terminal o configurarlas en pbx.json:

Flag Tipo Defecto Descripción
--start bool false Inicia el servidor web, el servicio AGI y los listeners de webhooks.
--db-setup bool false Inicializa las tablas y datos por defecto en SQLite o MySQL.
--wizard bool false Asistente interactivo por consola para configurar pbx.json.
--chat bool false Habilita la interfaz web de chat en /chat y el dashboard en /dashboard.
--web-port int 35248 Puerto HTTP para el Dashboard, Chat, Métricas Prometheus y APIs.
--asterisk bool false Activa el servidor FastAGI para atender llamadas de Asterisk.
--asterisk-agi string 127.0.0.1:4573 Dirección y puerto TCP donde escuchará el servidor FastAGI.
--ai-token string "" API Key del proveedor LLM (OpenAI, Groq, OpenRouter).
--llm-url string "" URL base del endpoint OpenAI-compatible (ej. http://localhost:11434/v1).

💾 Parámetros en Base de Datos (Tabla aiSettings)

Puedes modificar estos valores en vivo sin reiniciar el servidor desde el Menú de Administración (/):

  • llm_url: Endpoint de chat completions compatible con OpenAI.
  • ai_token: Clave de acceso a la API del modelo de IA.
  • model: Nombre del modelo (ej. gpt-4o-mini, llama-3.3-70b-versatile).
  • asr: Proveedor de reconocimiento de voz (google, openai).
  • tts: Proveedor de voz sintetizada (google, openai, elevenlabs).
  • timezone: Zona horaria local para marcas de tiempo (ej. America/Mexico_City).

📝 Prompts por Canal (Tabla aiPrompts)

PBX AI permite definir instrucciones personalizadas según el medio de contacto:

  • Canal `asterisk`: Instruye al LLM para que responda con frases breves, directas, sin caracteres especiales ni emojis, ideal para ser leído por teléfono.
  • Canal `chat`: Permite respuestas más detalladas, listas con viñetas, enlaces y formato Markdown.
  • Canal `all`: Prompt base del sistema compartido por todos los canales.

🛠️ Preguntas Frecuentes & Resolución de Problemas

❓ Asterisk reporta "AGI Connection Refused" en el puerto 4573

Causa: PBX AI no arrancó con el servicio Asterisk habilitado.
Solución: Asegúrate de incluir la flag --asterisk al iniciar el comando:
./build/pbx --start --asterisk --asterisk-agi 127.0.0.1:4573

❓ Recibo error "HTTP 429 Too Many Requests"

Causa: El limitador de tasa de seguridad de PBX AI restringe peticiones a 60 req/min por dirección IP para prevenir ataques de denegación de servicio y saturación de API.
Solución: Espera 60 segundos o revisa si algún script automatizado está enviando peticiones en bucle.

❓ Error: "no such table: aiLogs" o faltan datos

Causa: La base de datos SQLite o MySQL no ha sido inicializada.
Solución: Ejecuta el inicializador de base de datos una sola vez:
./build/pbx --db-setup --db-name pbx.db

❓ El audio de la llamada no se reproduce o se escucha en blanco

Causa: Falta la utilidad ffmpeg o sox en el sistema operativo del servidor para convertir archivos de audio temporal.
Solución: Instálalo mediante el gestor de paquetes de tu sistema:
En Debian/Ubuntu: sudo apt update && sudo apt install -y ffmpeg sox libsox-fmt-all
En macOS: brew install ffmpeg sox

Guía de Conexión e Integración Paso a Paso

Procedimiento completo de inicio a fin para conectar Web Chat, Asterisk PBX, WhatsApp / Meta y Telegram.

💬

Asistente Conversacional Web & Widget Embebido

Interfaz interactiva en tiempo real con respuestas transmitidas token por token mediante Server-Sent Events (SSE), entrada de texto, subida de archivos y modo llamada con detección de voz (VAD).

1

Habilitar Flags del Servidor Web y Audio Arranque

Para activar el frontend de chat y las capacidades de voz en el navegador, inicia PBX AI con las flags --chat y --chat-audio:

Terminal (Arranque con Web Chat) 
./build/pbx --start --db-name pbx.db --chat --chat-audio --web-port 35248

O defínelo en tu archivo pbx.json:

pbx.json 
{
  "chat": true,
  "chat_audio": true,
  "chat_cors": "*",
  "web_port": 35248
}
2

Configurar Motor de Inteligencia Artificial (LLM) aiSettings

Ingresa al Panel de Control Admin (http://localhost:35248/) en el módulo aiSettings y establece las credenciales del modelo:

  • LLM URL: https://api.openai.com/v1/chat/completions (o tu servidor local Ollama: http://localhost:11434/v1).
  • LLM Token: Tu clave secreta sk-proj-...
  • LLM Model: gpt-4o-mini (óptimo en costo/velocidad), gpt-4o o llama-3.3-70b-versatile.
3

Definir Política de Acceso y Usuarios Seguridad

En el módulo aiSettings encontrarás el campo userRestricted:

  • userRestricted = 0 (Desactivado): Modo público. Cualquier usuario que visite /chat puede conversar libremente sin autenticación.
  • userRestricted = 1 (Activado): Modo corporativo. Solo usuarios registrados en la tabla aiUsers pueden acceder. Cada usuario ingresa mediante su enlace personalizado con token:
    http://localhost:35248/chat?uuid=1090f87e2d45b8eac88ee44097ef8fc2
4

Incrustar el Widget en tu Sitio Web o Tienda HTML & Iframe

Puedes incrustar el asistente en cualquier página HTML (WordPress, Shopify, Next.js, HTML estático) con este código responsive flotante:

HTML Widget Snippet

<iframe

  width="400" 
  height="600" 
  style="position: fixed; bottom: 20px; right: 20px; border: none; border-radius: 16px; box-shadow: 0 12px 36px rgba(0,0,0,0.4); z-index: 9999;"
  allow="microphone">
</iframe>
5

Validación y Pruebas en Vivo Test

Abre en tu navegador http://localhost:35248/chat. Escribe un mensaje de prueba o pulsa el icono de micrófono para iniciar una llamada de voz bidireccional.

Prueba por Terminal vía cURL 
curl -N -X POST "http://localhost:35248/chat?stream=true" \

📞

Telefonía Asterisk PBX & Agente de Voz FastAGI

Conexión de ultra baja latencia con tu central telefónica Asterisk. PBX AI contesta la llamada vía FastAGI, transcribe la voz del llamante en tiempo real con Whisper, consulta al LLM y sintetiza la voz directamente al canal telefónico.

1

Instalar Dependencias de Conversión de Audio en el Sistema Servidor

Asterisk requiere que el audio se transmita a 8000 Hz, Mono, PCM 16-bit (.wav o .sln). PBX AI realiza esta conversión automáticamente utilizando ffmpeg y sox:

En Servidor Debian / Ubuntu 
sudo apt update && sudo apt install -y ffmpeg sox libsox-fmt-all
En macOS (Homebrew) 
brew install ffmpeg sox
2

Iniciar PBX AI con el Servicio FastAGI Habilitado Puerto 4573

Inicia PBX AI agregando el flag --asterisk y opcionalmente especificando el puerto de escucha AGI (por defecto 127.0.0.1:4573):

Comando de Ejecución 
./build/pbx --start --db-name pbx.db --asterisk --asterisk-agi 127.0.0.1:4573

O en tu pbx.json:

pbx.json 
{
  "asterisk": true,
  "asterisk_agi": "127.0.0.1:4573"
}
3

Configurar Dialplan en Asterisk (/etc/asterisk/extensions.conf) Dialplan

Edita tu archivo /etc/asterisk/extensions.conf y define una extensión (ej. 900) para derivar la llamada hacia el servicio FastAGI:

/etc/asterisk/extensions.conf 
[from-internal]
; Extensión 900: Atendida por PBX AI Voice Assistant
exten => 900,1,NoOp(=== PBX AI - Conectando Llamada con Asistente ===)
 same => n,Answer()
 same => n,Wait(1)
 same => n,AGI(agi://127.0.0.1:4573)
 same => n,Hangup()

Aplica los cambios en la consola de Asterisk sin reiniciar el servicio:

Asterisk CLI 
asterisk -rx "dialplan reload"
4

Registrar Extensiones SIP en el Módulo aiSip aiSip

Entra al Panel de Control (http://localhost:35248/) en el módulo aiSip y da de alta las extensiones autorizadas (ej. 101, 102, 103) o troncales. Esto permite a PBX AI reconocer al llamante y aplicar sus preferencias de idioma y nombre automáticamente.

5

Configurar TTS, ASR y VAD en aiSettings Voz

En el módulo aiSettings:

  • TTS Provider: openai (o elevenlabs para la máxima naturalidad).
  • TTS Voice: alloy, nova u onyx.
  • ASR Provider: openai (modelo whisper-1).
  • Asterisk VAD: 1 (activa la detección automática de silencio para interrumpir o contestar inmediatamente cuando el usuario deja de hablar).
  • Asterisk MOH: 1 (música de espera mientras el LLM procesa la respuesta).
6

Directivas de Transferencia y Cuelgue de Llamada Comandos

PBX AI reconoce comandos especiales en corchetes dentro de la respuesta del modelo:

  • [sip:102] o [sip:soporte]: Asterisk realiza una transferencia inmediata de la llamada a la extensión 102.
  • [close]: Asterisk cuelga la llamada de forma limpia tras despedirse del usuario.
Consejo de Prompt: En aiPrompts para el canal asterisk agrega: "Si el llamante pide hablar con una persona, di 'Te transfiero con soporte' e incluye la etiqueta [sip:soporte]. Al finalizar la llamada incluye [close]."
7

Prueba Real con Softphone (Zoiper / MicroSIP / Linphone) Test

Conéctate a tu central Asterisk con cualquier softphone usando la extensión 101. Marca 900. Escucharás el saludo inicial del agente de voz y podrás hablar en lenguaje natural en tiempo real.

WhatsApp Business Cloud API (Meta)

Conexión directa y oficial con los servidores de WhatsApp de Meta. Permite atender conversaciones de texto y notas de voz con transcripción automática mediante Whisper y respuestas inteligentes.

1

Crear una App en Meta for Developers Meta Portal

  1. Ingresa en developers.facebook.com con tu cuenta de Facebook/Meta.
  2. Haz clic en Mis Apps → Crear App.
  3. Selecciona el tipo de app: Business (Negocios).
  4. En la lista de productos disponibles, localiza WhatsApp y haz clic en Configurar.
2

Obtener Phone Number ID y Token Permanente Credenciales

En el menú lateral de WhatsApp → Introducción (Getting Started):

  • Identificador de número de teléfono (Phone Number ID): Copia este número numérico (ej. 109283746592810). Este será tu metaUser.
  • Token de Acceso Permanente: En Meta Business Suite → Configuración del Negocio → Usuarios del Sistema (System Users), crea un usuario administrador con permisos whatsapp_business_messaging y genera un token sin vencimiento. Este será tu metaAuth.
3

Configurar en PBX AI (aiSettings o pbx.json) aiSettings

En el módulo aiSettings del panel de administración o en pbx.json completa los siguientes campos:

Valores en pbx.json / aiSettings 
{
  "meta_url": "https://graph.facebook.com/v20.0/109283746592810/messages",
  "meta_user": "109283746592810",
  "meta_auth": "Bearer EAABwzLp12k8BAOzKeyDemoWhatsAppCloudAPI2024...",
  "meta_token": "mi_clave_secreta_webhook_verificacion_123"
}
4

Configurar Webhook en el Panel de Meta Webhook /meta

  1. En el panel de Meta → WhatsApp → Configuración → Webhook, haz clic en Editar.
  2. URL de devolución de llamada: https://tu-dominio.com/meta (requiere HTTPS con certificado válido, o un túnel ngrok: https://xxxx.ngrok-free.app/meta).
  3. Token de verificación: Escribe exactamente el mismo valor de meta_token (ej. mi_clave_secreta_webhook_verificacion_123).
  4. Haz clic en Verificar y Guardar. PBX AI responderá al handshake criptográfico de Meta con HTTP 200 y el challenge.
5

Suscribirse al Campo 'messages' Eventos

En la misma sección de Webhook en Meta, en la tabla Campos del Webhook, busca `messages` y haz clic en Suscribirse. A partir de ese instante, cada mensaje o audio enviado a tu número de WhatsApp será reenviado a PBX AI.

6

Pruebas de Texto y Notas de Voz en WhatsApp Test

Envía un WhatsApp al número configurado diciendo "Hola, ¿cuál es el horario de atención?". PBX AI responderá de forma instantánea. Si envías una nota de voz, el bot descargará el audio OGG, lo transcribirá con Whisper y enviará la respuesta por WhatsApp.

Bot de Telegram Oficial

Canal de mensajería instantánea mediante la API de Telegram Bots. Admite respuestas formateadas con Markdown, notas de voz transcritas con Whisper, comandos de reset (/reset) y ayuda (/help).

1

Crear el Bot con @BotFather en Telegram BotFather

  1. Abre la aplicación de Telegram y busca al usuario oficial verificado @BotFather.
  2. Envía el comando /newbot.
  3. Escribe el nombre visible de tu bot (ej. Asistente IA PBX).
  4. Escribe el username público del bot (debe terminar obligatoriamente en bot, ej. mi_empresa_ia_bot).
2

Copiar el HTTP API Token API Token

BotFather responderá confirmando la creación y te entregará el token de acceso:

Ejemplo de Token de Telegram 
7182938475:AAH_DEMO_PBX_AI_BOT_TOKEN_TELEGRAM_2024
3

Guardar el Token en PBX AI (aiSettings o pbx.json) aiSettings

En el Panel de Administración (http://localhost:35248/) accede al módulo aiSettings y pega tu token en el campo Telegram Token, o en pbx.json:

pbx.json 
{
  "telegram_token": "7182938475:AAH_DEMO_PBX_AI_BOT_TOKEN_TELEGRAM_2024"
}
4

Registrar el Webhook Oficial de Telegram hacia tu PBX AI Webhook /tg

Ejecuta en tu terminal el siguiente comando cURL (requiere HTTPS en tu dominio o ngrok):

Comando cURL de Registro de Webhook 
curl -F "url=https://tu-dominio-publico.com/tg" https://api.telegram.org/bot7182938475:AAH_DEMO_PBX_AI_BOT_TOKEN_TELEGRAM_2024/setWebhook

Telegram responderá confirmando el registro exitoso:

Respuesta Esperada 
{"ok": true, "result": true, "description": "Webhook was set"}
5

Gestión de Usuarios en aiUsers Usuarios

Si userRestricted = 0 en aiSettings, cualquier persona de Telegram puede hablar con el bot. Si deseas restringir el acceso a clientes o personal autorizado, registra el chat ID numérico o username del usuario en el módulo aiUsers.

6

Pruebas de Texto, Comandos y Notas de Voz Test

Abre el chat de tu nuevo bot en Telegram, pulsa Iniciar (/start) y escribe cualquier mensaje. También puedes probar comandos del sistema como /reset para reiniciar la memoria de la conversación o /help para consultar las acciones disponibles.
